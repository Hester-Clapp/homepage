Data Structures

Stacks

A stack is an abstract data structure based on an array, that operates on a first-in, last-out basis (FILO). Items can be pushed onto the top of the stack, and popped off the top too.

Stacks are very fast since they only have one pointer (to keep track of where the top is), and items do not need to be moved.

Stacks are used to keep track of function calls, store browser history, and traverse graphs depth-first.
