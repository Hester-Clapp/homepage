Data Structures

Records

A record is an abstract data structure designed for databases, which is based on a hash table. It contains multiple pieces of data, which can be of many different types, which are indexed by a key or field instead of a number.

Similarly to a hash table, a record makes use of hashing to store data in an array. The main difference is that data is stored as a key-value pair, consisting of an array of length 2.

Records are fundamental to flat-file and relational databases, which are arrays of record which all have the same keys.
