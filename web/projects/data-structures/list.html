Linked Lists

A linked list is a composite, dynamic data structure which stores multiple pieces of data in order. Unlike static data structures like arrays, the contents of a linked list are not necessarily all stored in the same location, and may be distributed all over memory.

To keep track of the order, each item is treated as a node, which contains a value and a pointer that stores the location of the next item in the list. The first item is pointed to by a separate "head pointer", and the last item points to null.

In a double linked list, each node points to the item before and the item after it, which can speed up insertion, but also introduces redundancy.

Because of their dynamic nature, it is very easy to add or remove items from linked lists. The new item can simply be stored in the next available memory location, pointed to by a "next free pointer", made to point to the item that follows it, and then the item that preceeds it must be found to point to the new item.
