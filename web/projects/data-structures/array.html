Data Structures

Arrays

An array is a composite data structure which stores multiple pieces of data in order. Conventionally, this data is all of the same primitive data type.

Arrays are static data structures, which means they are a fixed length. You cannot add items to an array if all of the indices are full. However, arrays are mutable, which means the data inside them can be changed after it is written.

Arrays form the basis of many abstract data types, such as stacks, queues and hash tables.
