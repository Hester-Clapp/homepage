Hash Tables

A hash table is an abstract data structure based on a circular array which is designed to be queried in constant time. This means the amount of time it takes to check if an item is in the table is independent from the number of items in the table.

When items are added, the item itself is passed through a hash function, which returns a numerical value. This is then used as the index of the item. Similarly, when querying the table, the query itself is hashed, and the table checks if there is an item at that index.

This means the first index checked is usually the correct target, but sometimes different items will hash to the same value. To prevent this, a technique called linear probing is used.

If an item is added to an index which is already full, the table simply looks for the next empty slot in the table. Querying is slightly more complex - if there is an item at the index but it is not the same as the query, the table will perform a linear search, starting at the index and stopping when the target is found (and returns true) or until an empty space is found (and returns false).
