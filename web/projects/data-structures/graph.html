Graphs

A graph is a non-linear abstract data structure, consisting of nodes (or vertices), which are connected by edges (or links). Sometimes the edges are directional, in which case the graph is called "directed", and sometimes they have weights (such as distance or cost), which means the graph is "weighted".

The graph is implemented with a set of nodes, stored in an array or linked list, and then either an adjacency matrix or adjacency list.

An adjacency matrix is a sparse 2D array, meaning not all of the possible spaces are occupied, with dimensions n by n, where n is the number of nodes. If there is a value (for example) at index (2,1), then there is an edge from node 2 to node 1. For a weighted graph, the value here is the weight of the edge, but for a non-directed graph it is simply a true Boolean.

Alternatively, an adjacency list is an array or record of length n, which stores a list of all of the other nodes which the node is adjacent to. These nodes are known as the node's children.

Graphs can be used to model problems, such as navigating a road network, managing projects, or finding the optimal route through a computer network.
