Coding Experience

Scratch

Everyone has to start somewhere! I had dabbled with bits of Scratch throughout primary school - I remember Scratch 2.0 coming out in 2013 - but I really got into it in 2015, when I started making games and educational projects alongside schoolwork. A few of my projects are public on my Scratch profile, although many of them are forks of other people's projects. I went back to Scratch briefly during the pandemic, but I have since moved on to more advanced languages.

Lua (Roblox)

During the summer holidays in 2015, I went on a 5-day course to learn how to use the Roblox Studio game engine. This makes it easy to create meshes and handles physics and server management for you, making it straight forward to create a basic game with little coding. Although slow at first, I did gradually start to learn to use Lua scripts to add more complex functionality. However, questionable business practices from Roblox have left me with little motivation to use the game engine, and I have mostly moved on from this now.

JavaScript (p5js)

In 2018 I joined secondary school, and began having regular computer science lessons every 2 weeks. In year 7, we spent a short while using C# to make simple text-based programs, though I did not learn enough to make anything more than this. While the majority of year 7 content was focused on ethics, online safety and fundamental content such as logic and binary, we did more coding in year 8 using a JavaScript library similar to the HTML canvas 2d context called p5js, which allowed us to draw shapes and make flags. This was my first experience with JavaScript, and I quite enjoyed it, though most of my projects were static vector images with little interactivity.

Python

At the end of 2021, I started the GCSE course, and we would be learning Python for use in the exam. I gradually worked through exercises on CSNewbs when not learning new content.

JavaScript (HTML and Bun)

Upon joining Cambridge Maths School in 2023, I revisisted JavaScript, but this time in a web environment. I picked it up quite quickly due to my previous experience with p5js, and I was inspired to make an infinite version of Minesweeper, which I had had the idea for in secondary school but failed to get working at the time. This success led me to make more canvas-based projects, a few of which drew inspiration from my concurrent school work in Computer Science and other subjects. JavaScript has since become my main programming language, and due to its versatility I have used it almost exclusively for the last two years

Alongside front-end JavaScript, we also used a modern runtime environment called Bun, which had only been released on our second day of school! We used back-end JavaScript while working on a database project using Bun and SQLite, and I also tried to make an io game inspired by Ultimate Frisbee using websockets. Later in the course I used both of these technologies to make a train journey planner for my NEA coursework.

Java

As part of my programme at TU Delft, I had to learn Java as a default high-level language for teaching programming concepts. While the strong-typed syntax took a little getting used to, it was very interesting to learn about object-oriented programming in a practical setting. Before starting at university, I had always seen objects as representations of physical objects like people or cars, but I soon learned to treat them more like components of a larger system that contain the knowledge and functionality of a certain part of the system. Furthermore, I learned about layered architectures which divide classes into layers from the UI at the top, business logic in the middle and backend processing at the lower level. Using classes in layers like this makes it much easier to add or improve features without affecting other parts of the program. While I prefer to code in JavaScript, I have started to apply these object-oriented principles in my personal projects as well as university assignments.
